## 受控实测

测试持有调度独占凭证，在同一已加载模型上直接测工作 API，避免其他请求混入。输入37–39 tokens，输出强制512 tokens（ignore_eos），关闭思考。每个采样区间后端完成计数恰好为1；使用实际 completion_tokens，分别计算首个输出块后的流式速度和后端 decode 时间。客户端估算包含首块的 tokens，不能当作逐 token 精确计时；两种计时结果基本一致。

| 内容 | temperature | 首token 秒 | 后端生成 token/s | 草稿接受率 | 每轮平均接受草稿 tokens |
|---|---:|---:|---:|---:|---:|
| 中文科普 | 0 | 0.083 | 76.5 | 18.0% | 1.26 |
| 英文科普 | 0 | 0.071 | 104.9 | 29.1% | 2.04 |
| 同一英文再次请求 | 0 | 0.068 | 104.7 | 29.1% | 2.04 |
| 中文科普 | 0.7 | 0.093 | 67.2 | 14.1% | 0.99 |
| 英文科普 | 0.7 | 0.073 | 107.9 | 31.0% | 2.17 |

这是少量特定提示词的结果，不是语言或模型整体性能评分。强制输出可能跨越模型原本的停止位置，与日常请求不完全相同。原始记录：`workspace/reports/llm-single-throughput-diagnosis.json`；可重跑工具：`.workbench/scripts/diagnose-llm-speed.py`。

## 已确认与待确认原因

1. **确有生成速度低于目标，不能只归因于面板取样。** 排除了网关、排队、冷启动、多路并发和大量输入。预填充约0.05–0.07秒，首token约0.07–0.09秒，主要时间在后续生成。
2. **DFlash接受率低，且随内容变化明显。** 7-token草稿每轮只接受约1–2个，随后还要继续校验和生成；当前推测解码收益受到限制。不能把草稿提出的 tokens 当作真实输出吞吐。
3. **运行策略与启动命令表面配置不一致。** 启动器的 speculative-config 写 `draft_sample_method=greedy`，但镜像默认 `PAITON_DFLASH_DRAFT_SAMPLE_METHOD=probabilistic` 与 `PAITON_DFLASH_RERANK=128`；入口 `paiton-qwen38` 调用 `prepare_server_args`，将实际配置覆盖为概率草稿 + R128候选池。该覆盖已从本机镜像环境和安装源码确认。匹配A/B已经完成：greedy/R0在temperature=0时没有提升，在temperature=0.7时更慢。不能把该默认覆盖视为本轮速度低的已证实根因；保留probabilistic/R128。
4. **当前没有观察到明显的GPU降频证据。** 测试末尾利用率96–98%，频率约3.26–3.31 GHz，功耗279–287W、上限300W，热点74–80°C；这不等同于完整硬件性能分析。
5. **当前服务是长上下文/并发配置。** 256K上限、8路服务上限、8GiB KV预算、CPU embedding、KV4及视觉开启。服务上限8本身不代表测试同时运行8路。已有长输入记录的生成估算约125–174 token/s，与本轮提示词、输出长度、运行时不完全相同，无法直接判断同条件回退。200 token/s尚未成为本机通用验收指标。

## 维护窗口匹配 A/B

同一输入、512输出tokens、关闭思考、seed=42，每个语言/temperature组合重复两次，以下为后端decode速度均值。

| 输入 | temperature | 默认 probabilistic/R128 | greedy/R0 | greedy/R0 关闭草稿压缩 |
|---|---:|---:|---:|---:|
| 中文科普 | 0 | 77.7 | 77.8 | 70.0 |
| 中文科普 | 0.7 | 68.2 | 58.2 | 52.2 |
| 英文科普 | 0 | 105.0 | 104.8 | 92.6 |
| 英文科普 | 0.7 | 108.4 | 96.6 | 86.8 |

单位token/s。greedy/R0的确定性速度基本不变，随机采样较默认回退约11–15%；关闭草稿压缩又比greedy/R0慢约10–12%，接受率没有改善，因此均未采用。前两组temperature=0输出SHA256相同；三项算术/代码表达式烟雾测试通过，这不构成完整质量验收。原始记录：`workspace/reports/llm-policy-ab.json`。

关闭快速草稿压缩时，R128不能同时开启，已从本机源码和启动失败日志确认。兼容组合采用greedy/R0、RADIANCE_FAST_DRAFT=0和RADIANCE_VERIFY_HEAD=0，加载预热约367秒；未关闭本机草稿原有FP8存储，该测试是撤销快速4-bit权重/2-bit输出头转换，不是BF16草稿测试。内部策略工具加入提前校验，校验通过后才停模型；测试无论成功/失败均恢复日常配置后释放独占凭证，避免测试参数留在生产服务。

内存驻留仍关闭，与本次诊断无关。200 token/s尚未达标；低接受率是观测到的限制，具体成因仍需对照验证。
