# 项目现状

文档整理：2026-10-20。当前模式以 [运行与调度](RUNTIME_TOPOLOGY.md) 为准；历史评测记录继续保留。

## 日常使用

通过 API / MCP 提交任务，网关按 `model` 自动排队、准备 GPU 后端并转发。H3 原生画布独立进入 ComfyUI 自身队列。单卡按需切换部署，最后使用的模型保持运行。

| 入口 | 地址 | 说明 |
|---|---|---|
| 工作台 | [127.0.0.1:13000](http://127.0.0.1:13000/) | 总览、任务、模型服务、API、MCP 与访问管理 |
| 公共 ComfyUI | [127.0.0.1:8188](http://127.0.0.1:8188/) | H3 原生画布与执行，不调用其他服务 API |
| 统一 API | `http://127.0.0.1:18982/v1` | 聊天、图像和视频生成 |

服务仅监听回环地址。公网及持久媒体任务需要有效密钥；本机同步调用保留可信兼容路径，详见 API。聊天采用 OpenAI 风格并支持 SSE，媒体采用项目 JSON 协议。首次加载、跨模型切换和视频生成需要较长超时。

调用格式见 [API 参考](CURRENT_API.md)，首次安装和日常命令见 [安装与运维](OPERATIONS.md)。

## 部署与能力

| API model | 已有能力与验证 | 主要限制 |
|---|---|---|
| `qwen38-27b-w3a4` | 文本、思考、CPU 视觉；已有长上下文与混合并发记录 | 技术上限 256K、并发上限 8；实际额度由面板配置，满载能力依赖 KV 预算 |
| `qwen-image21` | 文生图、透明图、单图/多参考图编辑 | 编辑纹理保真和角色一致性仍待验收 |
| `flux2-klein` | Paiton / Stock 文生图，公共 ComfyUI 路径通过 | 热态与首轮含编译耗时需分开比较 |
| `cosyvoice3-rl` | CosyVoice 3 RL：参考音频零样本克隆、Instruct 语气、`[shan4]` 拼音标注；仅 MCP `generate_audio` 持久任务 | 参考音频3–30秒，文本≤5000字；耗时与长期稳定性未系统测量 |
| `minimax-h3` | FL2VA文生/首尾帧；Ref2VA多图、参考视频与混合参考，含音频 | 最多9图+3视频；视频总参考时长≤15秒。单图20步864×480/15.08秒753.71秒、峰值21.17GiB；9图+3视频20步864×480/15.08秒1345.96秒、峰值22.935GiB；人物保真度仍需验收 |

当前保留五个模型服务。MCP 暴露生图、编辑、视频生成（H3 原版工作流，工具名 `generate_video`）和语音生成（`generate_audio`）四类工具，以及任务与作品下载；其他 ComfyUI 工作流使用原生 API，统一检测服务队列与历史；Wan 已下线并删除专用 Docker 镜像。

ComfyUI 只发布 7 个 H3 原生模板，金鱼只保留原版。通用 ComfyUI 工作流通过原生 API 提交；金鱼原版使用专用 MCP 工具，不在 ComfyUI 内调用其他服务 API。详见 [原生工作流](COMFYUI_NATIVE.md)。

## 当前运行策略

- LLM 使用固定模型名 `qwen38-27b-w3a4`。上下文、并发、Eager 和 KV 预算由面板配置，应用时等待已有任务结束并重启引擎；模型元数据发布已保存额度。
- CPU 视觉已接入，默认思考强度为 `medium`，关闭思考使用 `reasoning_effort: "none"`。主模型输出头使用 BF16，主干仍为 W3A4。
- 默认 KV 预算：上下文 ≤64K 为 8,859,648,000 字节，长上下文为 8 GiB；可通过面板自定义。每路额度乘并发不保证能同时满载。
- CPU 权重驻留保持关闭（`platforms/scheduler/residency.json` 的 `enabled: false`）。完整模型预热未通过，日常使用停止容器后冷加载。
- 活动 KV 的 RAM/GPU 分层仍属研究，未启用。

配置及容量解释见 [LLM 配置](LLM_MODES.md)，冷切换与驻留实验见 [模型调度](MODEL_SCHEDULING.md)。
